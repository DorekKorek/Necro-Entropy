About the Project

🕹️  This is my first real programming project. My primary goal was to step out of the console/terminal environment, learn modern C++, and gain hands-on experience building interactive graphical applications using the SDL library.
    Instead of a passive simulation, Necro-Entropy turns the classic cellular automaton into a hostile environment: cells continuously multiply, mutate, and decay, creating an unpredictable hazard you have to dodge in real time.

⚙️  Language: C++
    Graphics & Input: SDL 2.0 (Simple DirectMedia Layer)
    Core Mechanics: Conway's Game of Life (Cellular Automata)
    Created as a personal learning milestone.
